# Contact Management System Using Python

A menu-driven Python application for managing contacts and their phone numbers.

## Features

- Add new contacts with a contact type: Family, Personal, Work, or Other.
- Prevent duplicate phone numbers.
- Search contacts by name or phone number.
- View saved contacts.
- Delete contacts by name or phone number.
- Use a simple text-based menu to navigate the application.

## Technologies

- Python
- Lists and dictionaries
- Loops and conditional statements
- String handling and user input

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the Python file:

   ```bash
   python 220259635.py
   ```

## Purpose

This project was created to practice Python fundamentals by building a practical, interactive contact-management application.
