# Python Contact Management System

## 📌 Project Description

A simple contact management system developed using Python. It allows users to add, search, display, and delete contacts through a menu-driven interface.

## ✨ Features

- Add contacts with names, phone numbers, and relationship types.
- Organize contacts into Family, Personal, and Work categories.
- Prevent duplicate phone numbers.
- Search for contacts by name or phone number.
- Delete contacts by name or phone number.
- Display all saved contacts.
- Support multiple phone numbers for one person.

## 🛠️ Technologies Used

- Python 3
- Lists and dictionaries
- Conditional statements
- Loops and functions
- User input and data validation

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the following command:
   ```bash
   Contact Management System Using Python.py
   ```

## 🎯 Project Goal

This project was created to practice Python programming fundamentals by developing a practical application for organizing and managing contacts.
